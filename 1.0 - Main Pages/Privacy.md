## This website

This site is a set of static files served by GitHub Pages. It sets no cookies,
runs no analytics, and loads no third-party scripts, fonts or images. The only
thing stored in your browser is your light/dark theme preference, kept in
`localStorage` on your device and never sent anywhere.

GitHub, as the host, may log requests (including IP addresses) for security and
abuse prevention. See [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement)
for details.
